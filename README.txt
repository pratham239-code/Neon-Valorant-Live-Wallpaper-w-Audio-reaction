# Neon Valorant Live Wallpaper

A music-reactive Valorant Neon wallpaper created for Lively Wallpaper.

The wallpaper continuously cycles the colors of the artwork through the hue spectrum. The speed of the color transition is controlled by the music playing on the PC.

Quiet music results in slower color movement, while louder and more energetic music increases the movement speed. Strong bass and beats can temporarily accelerate the color transition.

## Features

- Real-time system audio reaction
- Smooth global hue cycling
- Music-dependent color movement
- Bass and beat detection
- Beat-based acceleration
- Optional bass brightness pulse
- Adjustable color saturation
- Adjustable brightness
- Adjustable color range
- Audio smoothing
- Protection for dark areas
- Protection for near-white highlights
- Lively Wallpaper customization support
- WebGL-based rendering
- 1920x1080 artwork

## Installation

1. Download the latest wallpaper ZIP from the Releases section.
2. Open Lively Wallpaper.
3. Import the downloaded ZIP.
4. Apply the wallpaper.
5. Right-click the wallpaper and select `Customize`.
6. Adjust the settings according to your preference.
